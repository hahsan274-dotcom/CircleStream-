# Circle Play
iOS-styled streaming browser for an open HTTP/FTP media server (default: http://new.circleftp.net/).

## Get the APK (no installs needed)
1. Create a free GitHub repo, upload everything in this folder (keep the `.github` folder).
2. Open the repo > Actions > "Build APK" > wait ~5 min.
3. Open the finished run > Artifacts > download `CirclePlay-apk`, unzip, install the APK.

Change the server address any time with the gear icon.
